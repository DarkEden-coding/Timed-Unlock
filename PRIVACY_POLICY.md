# Privacy Policy for Website Focus Lock

Last Updated: 4/28/2025

## Introduction

Website Focus Lock ("we", "our", or "the extension") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, and safeguard your information when you use our browser extension.

## Information We Collect

### Local Storage Data
The extension stores the following information locally in your browser:
- List of domains (websites) you have chosen to lock
- Custom timer durations for each locked website
- Active unlock timer states

This data is stored locally on your device using Chrome's storage API and is not transmitted to any external servers.

### Website Access
The extension requires access to website URLs to:
- Determine which websites you want to lock
- Apply lock screens to specified domains
- Control media playback when locking sites

### Temporary Data
Temporary data may include:
- Current tab URL information
- Active timer states
- Lock screen status

## How We Use Your Information

### Local Storage Usage
We use locally stored data to:
- Remember which websites you've chosen to lock
- Maintain your custom timer settings
- Ensure lock states persist between browser sessions
- Synchronize lock states across multiple tabs

### Website Data Usage
Website URL data is used solely to:
- Apply lock screens to specified domains
- Manage lock states across tabs
- Control media playback on locked sites

## Data Sharing and Transfer

### No External Data Transfer
- We do not collect, transmit, or store any data on external servers
- All information remains locally on your device
- No personal information is shared with third parties
- No analytics or tracking systems are implemented

## Data Security

### Local Storage Security
- All data is stored locally using Chrome's secure storage API
- Data is only accessible by the extension itself
- No external access to stored information is possible
- Data is protected by your browser's security mechanisms

## Your Rights and Control

You have the right to:
- Clear all stored data by removing the extension
- Reset all settings within the extension
- Control which websites are locked/unlocked
- Customize timer durations
- Access and manage all stored data through your browser

## Changes to Stored Data

You can modify or delete stored data by:
1. Removing website locks through the extension interface
2. Adjusting timer settings in the extension popup
3. Clearing browser data for the extension
4. Uninstalling the extension

## Required Permissions

The extension requires the following permissions:
1. **Storage Permission**
   - Purpose: Save lock states and settings
   - Scope: Local browser storage only

2. **Tabs Permission**
   - Purpose: Monitor and manage locked websites
   - Scope: Access to tab URLs and states

3. **ActiveTab Permission**
   - Purpose: Interact with current website
   - Scope: Limited to active tab only

4. **Scripting Permission**
   - Purpose: Implement lock screen and control media
   - Scope: Content modification on locked sites

5. **Host Permission**
   - Purpose: Function on any website you choose to lock
   - Scope: Access to modify webpage content

## Children's Privacy

The extension does not knowingly collect any personal information from children under 13 years of age.

## Updates to Privacy Policy

We may update this Privacy Policy periodically. Any changes will be reflected in the "Last Updated" date at the top of this policy.

## Contact Information

For any questions or concerns about this Privacy Policy, please:
- Create an issue on our GitHub repository
- Contact us through the Chrome Web Store listing

## Compliance

This extension complies with:
- Chrome Web Store Developer Program Policies
- General Data Protection Regulation (GDPR)
- California Consumer Privacy Act (CCPA)

## Data Removal

To completely remove all stored data:
1. Right-click the extension icon
2. Select "Remove from Chrome..."
3. Confirm removal

This will delete all locally stored data associated with the extension.
